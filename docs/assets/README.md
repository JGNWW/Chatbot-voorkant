# Avatar

Plaats hier het chat-icoon als **`avatar.png`** (vierkant, bv. 256×256 of groter).

De app toont dit als ronde avatar naast elk antwoord. Zolang `avatar.png`
ontbreekt, valt de app terug op een tijdelijk 🐶-emoji.

Aanleveren kan via GitHub: *Add file → Upload files* in deze map, bestandsnaam
`avatar.png`.
